# Entscheidungsnotizen (ADR)

Jeder Spike und jede größere Architekturentscheidung endet mit einer Notiz in diesem Ordner – auch wenn die Hypothese widerlegt wurde.

Dateiname: `NNNN-<kurzer-titel>.md`, fortlaufend nummeriert (`0001-roslyn-5.md`).

## Vorlage

```markdown
# NNNN – <Titel>

- Status: vorgeschlagen | entschieden | ersetzt durch NNNN
- Datum: YYYY-MM-DD
- Spike/Issue: S<x> / #<nummer>

## Frage
Was sollte geklärt werden?

## Ergebnis
Was wurde ausprobiert, was kam heraus (Messwerte mit Einheit)?

## Entscheidung
Was gilt ab jetzt? Welche Ausweichlösung wurde ggf. gewählt?

## Folgen
Was ändert sich für Inhalte, Komponenten, CI? Welche Inhalte sind jetzt freigegeben?

## Quellen
Offizielle Doku, Issues, Versionen.
```
