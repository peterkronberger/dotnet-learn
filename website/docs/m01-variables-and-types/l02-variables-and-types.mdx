## Variablen deklarieren

Eine <Term id="variable">Variable</Term> hat einen **<Term id="type">Typ</Term>**, einen **Namen** und einen **Wert**. C# ist <Term id="static-typing">statisch typisiert</Term>: Der <Term id="compiler">Compiler</Term> kennt den Typ schon vor dem Start und meldet Fehler früh.

<CodeBlock language="csharp" title="Variablen">{variables}</CodeBlock>

`var` lässt den Compiler den Typ <Term id="type-inference">ermitteln</Term>; er steht danach trotzdem fest.

Das `$` vor dem Text erzeugt einen **<Term id="string-interpolation">interpolierten String</Term>**. Ausdrücke in geschweiften Klammern werden ausgewertet und eingesetzt.

## Die wichtigsten Typen

| Typ | Beispiel | Wofür |
| --- | --- | --- |
| `int` | `42` | ganze Zahlen (32 Bit) |
| `double` | `3.14` | Gleitkommazahlen (64 Bit) |
| `decimal` | `19.99m` | Dezimalzahlen, z. B. Geldbeträge (128 Bit) |
| `bool` | `true` | Wahrheitswert |
| `char` | `'A'` | ein einzelnes Zeichen |
| `string` | `"Hallo"` | Text |

<details>
<summary>Vertiefung: Wert- und Referenztypen (optional)</summary>

Zahlen, `bool` und `char` sind **<Term id="value-type">Werttypen</Term>**: Eine Zuweisung kopiert den Wert. Klassen sind **<Term id="reference-type">Referenztypen</Term>**: Eine Zuweisung kopiert nur den Verweis, beide Variablen zeigen auf dasselbe Objekt.
