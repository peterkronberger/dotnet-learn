## Texte mit + verketten

Ein Text hat in C# den Typ `string`. Du kennst ihn aus den Textliteralen wie `"bob"`. Texte kannst du aneinanderhängen, mit demselben Operator `+`, den du von Zahlen kennst. Das heißt <Term id="string-concatenation">Verkettung (String Concatenation)</Term>. Steht links oder rechts von `+` ein `string`, wird der andere Operand in Text umgewandelt und angehängt. Eine Zahl wird dabei nicht addiert ([§12.12.5 Addition operator](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/expressions#12125-addition-operator)).

`+` wird von links nach rechts ausgewertet (Lektion über Operatoren). Deshalb kommt es auf die Reihenfolge an: Solange beide Operanden Zahlen sind, wird gerechnet. Erst wenn ein Text dazukommt, wird verkettet.

:::info[Vorhersage]
Welche vier Zeilen gibt das Programm aus? Notiere für jeden Ausdruck zuerst, welche Operanden das erste `+` hat.
:::

<CSharpRunner id="m01-l06-concat" code={concat} predict expected={concatOutput} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Die Ausgabe sind vier Zeilen: `34`, `33`, `312` und `Failed logins: 7`.

1. **Reihenfolge festlegen:** `+` wird von links nach rechts ausgewertet. Das erste `+` entscheidet, ob addiert oder verkettet wird.
2. **`"3" + 4`:** Ein Operand ist ein Text. Die `4` wird zu `"4"`, das Ergebnis ist `"34"`.
3. **`1 + 2 + "3"`:** Das erste `+` hat zwei Zahlen und addiert zu `3`. Das zweite `+` verkettet `3` und `"3"` zu `"33"`.
4. **`"3" + 1 + 2`:** Das erste `+` verkettet zu `"31"`, das ist ein Text. Das zweite `+` hängt `2` an: `"312"`.
5. **Beschriftung:** `"Failed logins: " + 7` ergibt `Failed logins: 7`.

Was passiert, wenn du `"3" + (1 + 2)` schreibst? Probiere es aus: Die Klammern erzwingen, dass zuerst gerechnet wird. Das Ergebnis ist `33`.

</details>

## Interpolation: Text aus Werten bauen

Lange Ketten aus `+` sind schwer zu lesen. Besser ist die <Term id="string-interpolation">String-Interpolation (String Interpolation)</Term>: Ein `$` steht vor dem Anführungszeichen, und in geschweiften Klammern steht ein Ausdruck, der ausgewertet und in den Text eingesetzt wird ([§12.8.3 Interpolated string expressions](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/expressions#1283-interpolated-string-expressions)). Das Beispiel `$"User {user} failed {count} times."` ist ein ganzer Satz mit zwei Lücken. Es gibt auch eine Form `$@"…"`, die die Interpolation mit einem wörtlichen Text verbindet. Der Kurs verwendet sie nicht.

Hinter dem Ausdruck stehen zwei optionale Teile:

- **Breite:** `{count,5}` füllt den Wert mit Leerzeichen auf mindestens 5 Zeichen auf. Eine positive Zahl richtet rechts aus, eine negative (`{user,-5}`) links.
- **Formatangabe:** `{rate:F1}` bestimmt nach dem Doppelpunkt, wie der Wert als Text aussieht. Eine <Term id="format-string">Formatangabe (Format String)</Term> wie `F1` zeigt eine Zahl mit einer Nachkommastelle, gerundet ([Standard numeric format strings](https://learn.microsoft.com/dotnet/standard/base-types/standard-numeric-format-strings)).

Soll ein Text eine geschweifte Klammer enthalten, schreibst du sie doppelt: `{{`.

:::info[Vorhersage]
Welche fünf Zeilen gibt das Programm aus? Überlege dir besonders die letzten drei: Wie viele Leerzeichen stehen in den eckigen Klammern?
:::

<CSharpRunner id="m01-l06-interpolation" code={interpolation} predict expected={interpolationOutput} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Die Ausgabe sind fünf Zeilen: `User bob failed 5 times.`, `Sum: 7`, `Rate: 71.4 %`, `[    5]` und `[bob  ]`.

1. **Ausdrücke einsetzen:** `{user}` und `{count}` werden durch `bob` und `5` ersetzt. In `{count + 2}` steht ein ganzer Ausdruck: `5 + 2` ergibt `7`.
2. **Formatieren:** `{rate:F1}` zeigt `71.4286` mit einer Nachkommastelle: `71.4`. Das ` %` danach ist normaler Text.
3. **Rechts ausrichten:** `{count,5}` ist 5 Zeichen breit. Die `5` hat ein Zeichen, davor stehen vier Leerzeichen.
4. **Links ausrichten:** `{user,-5}` ist 5 Zeichen breit, links ausgerichtet. Hinter `bob` stehen zwei Leerzeichen.

</details>

:::info[Hinweis]
Wie eine Zahl als Text aussieht, kann von der Kultur abhängen. Manche Kulturen schreiben `71,4` statt `71.4`. Der Playground und die Prüfung dieses Kurses laufen kulturunabhängig (`InvariantGlobalization`), deshalb steht in allen Ausgaben ein Punkt.
:::

## Ein Text hat Mitglieder

Ein `string` bringt eigene Fähigkeiten mit. Du verwendest sie mit einem Punkt hinter dem Namen. Hier genügt dir: Ein Text hat Mitglieder, und du rufst sie mit einem Punkt ab.

<Forward concepts={['Member (Mitglied) eines Typs']} module="6" />

- `name.Length` ist die Anzahl der Zeichen ([String.Length](https://learn.microsoft.com/dotnet/api/system.string.length)). Es steht ohne Klammern.
- `name.ToUpper()` ist eine <Term id="method">Methode</Term>, die den Text in Großbuchstaben liefert ([String.ToUpper](https://learn.microsoft.com/dotnet/api/system.string.toupper)). Sie hat Klammern.

:::info[Vorhersage]
Welche vier Zeilen gibt das Programm aus? Achte auf die dritte Zeile.
:::

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Die Ausgabe sind vier Zeilen: `3`, `BOB`, `bob` und `BOB`.

1. **Länge abrufen:** `name.Length` zählt die Zeichen von `bob`: `3`.
2. **Neuen Text erzeugen:** `name.ToUpper()` liefert einen neuen Text `BOB`.
3. **Alten Text prüfen:** `name` ist unverändert `bob`. Die Methode gibt das Ergebnis zurück und ändert die Variable nicht.
4. **Ergebnis speichern:** Erst `string shout = name.ToUpper();` hält das Ergebnis in einer Variable fest.

</details>

## Mehrzeiliger Text als Raw-String-Literal

Ein normales Textliteral braucht für Anführungszeichen und Zeilenumbrüche <Term id="escape-sequence">Escape-Sequenzen</Term> wie `\"` und `\n`. Ein <Term id="raw-string-literal">Raw-String-Literal (Raw String Literal)</Term> beginnt und endet mit mindestens drei Anführungszeichen. Dazwischen steht der Text, wie er ist: über mehrere Zeilen, mit Anführungszeichen und ohne Escape-Sequenzen. Die Einrückung des schließenden `"""` wird von allen Zeilen entfernt ([§6.4.5.6 String literals](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/lexical-structure#6456-string-literals)). Raw-String-Literale gibt es ab C# 11. Es gibt sie auch als interpolierte Form, die der Kurs nicht verwendet.

Die Ausgabe zeigt zwei Zeilen ohne Einrückung, die Anführungszeichen um `login-failed` stehen unverändert. Der Text beginnt in der Zeile nach den öffnenden `"""` und endet vor dem schließenden `"""`.

## Typische Fehlvorstellungen

:::warning[Achtung]
<Misconception id="m01-l06-string-plus-number-adds" />

**„`"3" + 4` ergibt `7`.“** Sobald ein Operand ein Text ist, verkettet `+`. Die Zahl wird zu Text, das Ergebnis ist der Text `"34"`. Gerechnet wird nur, solange beide Operanden Zahlen sind. Bei `1 + 2 + "3"` wird deshalb zuerst addiert (`3`) und dann verkettet (`"33"`).
:::

:::warning[Achtung]
<Misconception id="m01-l06-toupper-changes-variable" />

**„`name.ToUpper()` ändert `name`.“** Die Methode liefert einen neuen Text in Großbuchstaben. Die Variable `name` bleibt, wie sie war. Willst du das Ergebnis behalten, speicherst du es: `name = name.ToUpper();`.
:::

## Zusammenfassung

Texte hängst du mit `+` aneinander. Ist ein Operand ein Text, wird der andere in Text umgewandelt, und bei mehreren `+` zählt die Reihenfolge von links nach rechts. Mit Interpolation (`$"…{x}…"`) setzt du Werte direkt in einen Text ein. Breite (`{x,5}`) und Formatangabe (`{x:F1}`) bestimmen, wie sie aussehen. Ein Text hat Mitglieder wie `Length` und `ToUpper()`, die einen neuen Wert liefern. Ein Raw-String-Literal (`"""…"""`) schreibt mehrzeiligen Text ohne Escape-Sequenzen.
