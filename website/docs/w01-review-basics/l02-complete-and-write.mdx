# Code ergänzen und schreiben

:::note[Lernziele]
- Du erkennst bei einer Schreibaufgabe, welches Konzept aus den Modulen 1–4 gebraucht wird.
- Du ergänzt und schreibst kurzen Code zu den Modulen 1–4 so, dass er das verlangte Ergebnis liefert.
- Du erklärst in eigenen Worten, woran du das passende Konzept erkennst, und nennst eine Stelle, an der du es einsetzt.
:::

Jede Aufgabe hat zwei Schritte: Erst erkennst du das Konzept, dann ergänzt oder schreibst du den Code. Bei den Programmieraufgaben überlegst du vorher, was der Startcode ausgibt, und führst ihn dann aus.

### Aufgabe 9

<Quiz id="w01-l02-q20" />

:::info[Vorhersage]
`total` ist `7`, `count` ist `2`. Was gibt der Startcode aus? Welche Ausgabe soll er haben?
:::

Aufgabe: Das Ergebnis soll die Nachkommastelle behalten.

<CSharpRunner id="w01-l02-average" code={averageTask} tests={averageTests} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Der Startcode gibt `Average: 3` aus. Mit der Lösung gibt das Programm `Average: 3.5` aus.

<CodeBlock language="csharp" title="average-solution.cs">{averageSolution}</CodeBlock>

1. **Ursache:** `total / count` hat zwei `int`-Operanden. Die Division schneidet den Rest ab, das Ergebnis `3` wird erst danach zu `double`.
2. **Umwandlung:** `(double)total` macht einen Operanden zu `double`. Dann rechnet C# die ganze Division als Gleitkommadivision.

</details>

### Aufgabe 10

<Quiz id="w01-l02-q21" />

:::info[Vorhersage]
Der Startcode gibt immer `0` zurück. Was gibt er aus? Welche Summe soll `SumUpTo(4)` liefern?
:::

Aufgabe: Schreibe `SumUpTo` rekursiv. Sie addiert `n + (n - 1) + … + 1`.

<CSharpRunner id="w01-l02-sum-up-to" code={sumUpToTask} tests={sumUpToTests} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Der Startcode gibt `Sum: 0` aus. Mit der Lösung gibt das Programm `Sum: 10` aus.

<CodeBlock language="csharp" title="sum-up-to-solution.cs">{sumUpToSolution}</CodeBlock>

1. **Basisfall:** Bei `n == 0` gibt die Methode `0` zurück und ruft sich nicht mehr auf.
2. **Rekursiver Fall:** Sonst addiert sie `n` zu `SumUpTo(n - 1)`. Das Problem wird bei jedem Aufruf kleiner.

</details>

:::

Aufgabe: Das Programm soll `Name: unknown` ausgeben, wenn keine Zeile da ist.

<CSharpRunner id="w01-l02-default-name" code={defaultNameTask} stdin="" tests={defaultNameTests} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>
