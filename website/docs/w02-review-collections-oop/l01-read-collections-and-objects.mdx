# Sammlungen und Objekte: Code lesen

:::note[Lernziele]
- Du erkennst bei kurzem Code, welches Konzept aus den Modulen 5–8 das Verhalten bestimmt.
- Du sagst die Ausgabe von kurzem Code aus den Modulen 5–8 vorher oder findest die fehlerhafte Zeile, ohne den Code auszuführen.
- Du erklärst in eigenen Worten, woran du das passende Konzept erkennst, und nennst eine Stelle, an der du es einsetzt.
:::

:::info[Vorhersage]
Der Code ruft `Load` zweimal auf, einmal mit `12` und einmal mit `x`. Welche Zeilen erscheinen in welcher Reihenfolge?
:::

<CSharpRunner id="w02-l01-finally-flow" code={finallyFlow} predict expected={finallyFlowOutput} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Die Ausgabe ist `parsed`, `finally`, `12`, `bad text`, `finally` und `-1`.

1. **Erster Aufruf:** `parsed` erscheint, dann läuft `finally`. Erst danach gibt `Console.WriteLine` den Rückgabewert `12` aus.
2. **Zweiter Aufruf:** `int.Parse` wirft eine `FormatException`. Der `catch`-Block schreibt `bad text`, danach läuft `finally`, und `-1` wird zurückgegeben.

</details>

Die Ausgabe ist `1`, `20` und `10`.

1. **Struct:** `copy` ist eine Kopie, darum bleibt `points[0].X` gleich `1`.
2. **Zurückschreiben:** `points[1] = new Point { X = 20 };` ersetzt das Element in der Liste, darum erscheint `20`.

</details>

### Aufgabe 9

<Quiz id="w02-l01-q20" />

<Quiz id="w02-l01-q21" />

:::info[Vorhersage]
Das Programm löst dieselbe Exception zweimal aus, einmal mit `throw;` und einmal mit `throw ex;`. Welche eigene Methode steht jeweils zuerst im Stack Trace?
:::

<CSharpRunner id="w02-l01-rethrow-trace" code={rethrowTrace} predict expected={rethrowTraceOutput} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Bei `throw;` steht `at LogTools.Inner` zuerst, bei `throw ex;` steht `at LogTools.Outer` zuerst.

1. **`throw;`:** Der Stack Trace behält den ursprünglichen Ort des Fehlers in `Inner`.
2. **`throw ex;`:** Der Stack Trace beginnt neu an der Stelle des `throw` in `Outer`.

</details>
