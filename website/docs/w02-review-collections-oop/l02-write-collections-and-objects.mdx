# Sammlungen und Objekte: Code schreiben

:::note[Lernziele]
- Du erkennst bei einer Schreibaufgabe, welches Konzept aus den Modulen 5–8 gebraucht wird.
- Du ergänzt und schreibst kurzen Code zu den Modulen 5–8 so, dass er das verlangte Ergebnis liefert.
- Du erklärst in eigenen Worten, woran du das passende Konzept erkennst, und nennst eine Stelle, an der du es einsetzt.
:::

Jede Aufgabe hat zwei Schritte: Erst erkennst du das Konzept, dann ergänzt oder schreibst du den Code. Bei den Programmieraufgaben überlegst du vorher, was der Startcode ausgibt, und führst ihn dann aus.

### Aufgabe 4

<Quiz id="w02-l02-q10" />

:::info[Vorhersage]
Der Startcode legt zwei gleiche `Seat`-Objekte in ein `HashSet<Seat>`. Welche Zahl gibt er aus, und welche soll er ausgeben?
:::

Aufgabe: Ergänze `GetHashCode` in `Seat`, sodass gleiche Sitze nur einmal in der Menge stehen.

<CSharpRunner id="w02-l02-equals-hash" code={equalsTask} tests={equalsTests} />

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Der Startcode gibt `2` aus. Mit der Lösung gibt das Programm `1` aus.

<CodeBlock language="csharp" title="equals-hash-solution.cs">{equalsSolution}</CodeBlock>

1. **Ursache:** Ohne `GetHashCode` haben zwei gleiche Sitze verschiedene Hash-Codes. Die Menge hält sie darum für verschieden.
2. **Hash-Code:** `HashCode.Combine(Row, Number)` nimmt dieselben Werte, die `Equals` vergleicht.

</details>
