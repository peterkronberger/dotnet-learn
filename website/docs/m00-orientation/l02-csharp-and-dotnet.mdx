## Sprache und Plattform sind zwei Dinge

In der ersten Lektion hast du `Console.WriteLine("Hello");` geschrieben. Dahinter stecken mehrere Teile, die oft in einen Topf geworfen werden. Diese Lektion trennt sie.

<Term id="csharp">C#</Term> ist eine **Sprache**: Sie legt fest, wie du Code schreibst und was er bedeutet. Das steht in der <Term id="language-specification">Sprachspezifikation</Term>. Sie beschreibt „die Form“ und „die Interpretation“ von C#-Programmen. Sie beschreibt nicht, wie ein Programm für einen Computer übersetzt oder gestartet wird ([Scope](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/scope)).

<Term id="dotnet">.NET</Term> ist die **Plattform**, die C#-Programme ausführt. Microsoft nennt diese Komponenten ([Introduction to .NET](https://learn.microsoft.com/dotnet/core/introduction)):

| Teil | Aufgabe |
| --- | --- |
| Runtime (<Term id="clr">CLR</Term>, Laufzeitumgebung) | führt den übersetzten Code aus ([CLR overview](https://learn.microsoft.com/dotnet/standard/clr)) |
| Libraries (<Term id="bcl">BCL</Term>, Standardbibliothek) | fertige Typen und Methoden, zum Beispiel für JSON |
| Compiler (<Term id="roslyn">Roslyn</Term> für C#) | übersetzt Quelltext in ausführbaren Code |
| <Term id="sdk">SDK</Term> und Werkzeuge | bauen, testen und starten Projekte, zum Beispiel mit `dotnet build` |

## Sprache oder Bibliothek?

Die Spezifikation schreibt vor, dass jede Implementierung von C# eine kleine Standardbibliothek mitbringt. Sie enthält nur Typen, die die Sprache selbst braucht. Eine Implementierung liefert laut Spezifikation normalerweise eine viel größere Bibliothek mit ([Annex C: Standard library](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/standard-library)). Die Typen, die du täglich benutzt, stammen aus dieser größeren Bibliothek von .NET.

Ein Beispiel für die Grenze: Das Schlüsselwort `int` gehört zur Sprache. Die Spezifikation sagt, dass solche einfachen Typen Aliase (andere Namen) für Typen im Namespace `System` sind ([Types](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/types)). `typeof(int).FullName` fragt nach dem vollen Namen dieses Bibliothekstyps.

:::

2. **Alias auflösen:** Jedes Schlüsselwort steht für einen Typ der Bibliothek im Namespace `System`.

Du kannst also `int` oder `System.Int32` schreiben. Beides meint denselben Typ.

</details>

## Drei Quellen für „die Spezifikation“

Wenn du genau wissen willst, was in C# erlaubt ist, gibt es drei Schichten:

1. **ECMA-334:** der veröffentlichte Standard. Die neueste Ausgabe auf der Ecma-Seite ist die 7. Ausgabe (Dezember 2023); Ecma ordnet sie C# 7 zu ([ECMA-334](https://ecma-international.org/publications-and-standards/standards/ecma-334)). *Stand: 2026-10-25.*
2. **Entwurf des Standards auf Microsoft Learn:** der Arbeitstext der nächsten Ausgabe. Er enthält schon spätere Features ([C#-Spezifikation](https://learn.microsoft.com/dotnet/csharp/specification/)).
3. **Feature-Spezifikationen:** Der Standard liegt hinter der Implementierung zurück. Darum veröffentlicht Microsoft für neuere Features eigene Spezifikationen, bis der Standard sie aufnimmt ([Feature specifications](https://learn.microsoft.com/dotnet/csharp/specification/feature-spec-overview)).

Faustregel: Frage zuerst den Entwurf auf Microsoft Learn. Steht das Feature dort nicht, lies die Feature-Spezifikation. Für Fragen zu `Console`, `List<T>` oder anderen Bibliothekstypen hilft die Spezifikation nicht, dafür gibt es die Dokumentation der Bibliothek auf Microsoft Learn.

## Typische Fehlvorstellungen

:::warning[Achtung]
<Misconception id="m00-l02-csharp-is-dotnet" />

**„C# und .NET sind dasselbe.“** C# ist die Sprache. .NET ist die Plattform mit Laufzeitumgebung, Bibliothek, Compiler und SDK. .NET kann laut Microsoft auch Programme in anderen Sprachen ausführen, C# ist dabei die beliebteste ([Introduction to .NET](https://learn.microsoft.com/dotnet/core/introduction)).
:::

:::warning[Achtung]
<Misconception id="m00-l02-console-is-language" />

**„`Console.WriteLine` gehört zur Sprache C#.“** `Console` ist ein Typ der Bibliothek, `WriteLine` eine seiner Methoden. Die Sprache legt fest, wie ein Aufruf aussieht. Was `WriteLine` tut, steht in der Dokumentation der Bibliothek.
:::

</TabItem>

## Zusammenfassung

C# ist eine Sprache. Ihre Regeln stehen in der Spezifikation, die nur die Sprache beschreibt. .NET ist die Plattform mit Compiler (Roslyn), Laufzeitumgebung (CLR), Standardbibliothek (BCL) und SDK. Schlüsselwörter wie `var` und `int` gehören zur Sprache, `Console` und `Math` zur Bibliothek. Für Sprachfragen gibt es drei Quellen: den ECMA-Standard, den Entwurf auf Microsoft Learn und die Feature-Spezifikationen.
