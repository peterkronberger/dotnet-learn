## Ein Programm ist eine Folge von Anweisungen

Ein C#-Programm besteht aus <Term id="statement">Anweisungen</Term> (Statements). Jede Anweisung sagt dem Computer, was er tun soll, und endet mit einem Semikolon `;`. Der Computer führt sie nacheinander aus, von oben nach unten ([C#-Spezifikation, §13.3.2: Statement lists](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/statements)).

Eine Anweisung, die du sofort brauchst, ist `Console.WriteLine("Hello");`. Sie schreibt den Text in den Klammern als eine Zeile in die <Term id="console-output">Konsolenausgabe</Term>.

Der Text steht in Anführungszeichen. So ein Stück Text im Code heißt <Term id="literal">Literal</Term>; hier ein String-Literal. Mehr dazu kommt in Modul 1.

Du musst dafür keine weiteren Zeilen drumherum schreiben. Bei <Term id="top-level-statements">Top-level Statements</Term> ist die Datei das Programm: Der <Term id="compiler">Compiler</Term> (ein Programm, das deinen Code übersetzt und Fehler meldet, bevor das Programm läuft) macht aus den Anweisungen am Anfang der Datei den Startpunkt ([§7.1.3](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/basic-concepts)). Wie dieser Startpunkt genau aussieht, erfährst du in Modul 6.

## Write und WriteLine

`Console.WriteLine` beendet die Zeile nach dem Text. `Console.Write` schreibt den Text und bleibt in derselben Zeile ([Console.WriteLine](https://learn.microsoft.com/dotnet/api/system.console.writeline)).

:::info[Vorhersage]
Wie viele Zeilen gibt dieses Programm aus, und was steht in ihnen?
:::

<details>
<summary>Lösung und Erklärung anzeigen</summary>

Es sind zwei Zeilen: `Hello C#!` und `Next line`.

1. **Write:** Die ersten beiden Anweisungen schreiben `Hello ` und `C#` ohne Zeilenende. Das Leerzeichen in `"Hello "` gehört zum Text.
2. **WriteLine:** Die dritte Anweisung hängt `!` an und beendet die Zeile.
3. **Nächste Zeile:** Die vierte Anweisung schreibt in eine neue Zeile.

</details>

## Dein erster Fehler

Fehler gehören zum Lernen. Der Compiler meldet sie, bevor das Programm läuft. Probiere diese beiden im Runner aus: Ändere die Beispiele oben und schaue, was der Playground anzeigt.

- **Was passiert, wenn du die Anführungszeichen weglässt?** Dann steht dort `Console.WriteLine(Hello);`. Der Compiler kennt keinen Namen `Hello` und meldet einen Fehler.
- **Was passiert, wenn das Semikolon fehlt?** Dann steht dort `Console.WriteLine("Hello")` ohne `;`. Der Compiler erwartet ein Semikolon.

## Typische Fehlvorstellungen

:::warning[Achtung]
<Misconception id="m00-l01-text-without-quotes" />

**„Text wird auch ohne Anführungszeichen ausgegeben.“** Ohne Anführungszeichen liest der Compiler `Hello` als Namen. Gibt es keinen Namen `Hello`, ist das ein Fehler.
:::

:::warning[Achtung]
<Misconception id="m00-l01-statement-order" />

**„Die Reihenfolge der Anweisungen ist egal.“** Die Anweisungen laufen von oben nach unten. Tauschst du zwei `Console.WriteLine`-Zeilen, tauscht auch die Ausgabe.
:::

## Zusammenfassung

Ein C#-Programm ist eine Folge von Anweisungen, jede endet mit `;`. Sie laufen von oben nach unten. `Console.WriteLine` schreibt Text als eine Zeile, `Console.Write` bleibt in der Zeile. Text steht in Anführungszeichen, sonst liest der Compiler ihn als Namen und meldet einen Fehler. Mit Top-level Statements ist die Datei selbst das Programm.
