== 1. Read one incident ==
> GET /incidents/1 HTTP/1.1
> Accept: application/json
< 200 OK
< Content-Type: application/json; charset=utf-8
< body: {"id":1,"status":"open"}

== 2. Read an incident that does not exist ==
> GET /incidents/99 HTTP/1.1
> Accept: application/json
< 404 Not Found

== 3. Create an incident, twice ==
> POST /incidents HTTP/1.1
> Accept: application/json
> Content-Type: application/json; charset=utf-8
> body: {"user":"bob"}
< 201 Created
< Location: /incidents/3
< Content-Type: application/json; charset=utf-8
< body: {"id":3,"status":"open"}

> POST /incidents HTTP/1.1
> Accept: application/json
> Content-Type: application/json; charset=utf-8
> body: {"user":"bob"}
< 201 Created
< Location: /incidents/4
< Content-Type: application/json; charset=utf-8
< body: {"id":4,"status":"open"}

== 4. Replace the status, twice ==
> PUT /incidents/1/status HTTP/1.1
> Accept: application/json
> Content-Type: application/json; charset=utf-8
> body: {"status":"closed"}
< 200 OK
< Content-Type: application/json; charset=utf-8
< body: {"id":1,"status":"closed"}

> PUT /incidents/1/status HTTP/1.1
> Accept: application/json
> Content-Type: application/json; charset=utf-8
> body: {"status":"closed"}
< 200 OK
< Content-Type: application/json; charset=utf-8
< body: {"id":1,"status":"closed"}

== 5. Delete an incident, twice ==
> DELETE /incidents/2 HTTP/1.1
> Accept: application/json
< 204 No Content

> DELETE /incidents/2 HTTP/1.1
> Accept: application/json
< 404 Not Found

== 6. A method the path does not offer ==
> DELETE /incidents HTTP/1.1
> Accept: application/json
< 405 Method Not Allowed
