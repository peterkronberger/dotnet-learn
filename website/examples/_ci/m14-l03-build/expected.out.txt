== What the configuration changes ==
Debug: Optimize=false, DebugType=portable, DEBUG defined=yes
Release: Optimize=true, DebugType=portable, DEBUG defined=no

== Ways to start the Release build ==
$ dotnet run -c Release
Build: Release
Symbol AUDIT: set in the project file
Symbol FILE_SYMBOL: set with #define
$ ./m14-l03-build
Build: Release
Symbol AUDIT: set in the project file
Symbol FILE_SYMBOL: set with #define
$ dotnet m14-l03-build.dll
Build: Release
Symbol AUDIT: set in the project file
Symbol FILE_SYMBOL: set with #define
