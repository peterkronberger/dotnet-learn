# Audit spec draft clauses 15–24, annexes, feature specs C# 12–15 vs. module plan (issue #687, 2026-11-25)

Scope: C# standard draft on Microsoft Learn (clauses §15–§24 and the annexes), feature specifications and "What's new" pages of C# 12–15, "What's new in .NET 11" (overview). Compared with `concept/module-plan.md` (Reference table, **Spec** / **Library** / **Badge** lines of all modules, "Deliberately not covered"). Lesson texts were not read; one keyword search per open item in `website/docs` and `website/examples` was used to name lessons that already teach a topic.

Pages opened on 2026-11-25 are listed in the PR description ("Verification").

## Main results

1. **The draft has a new clause §18 "Extended indexing and slicing" (`ranges`).** All later clauses moved by one number: Interfaces §19, Enums §20, Delegates §21, Exceptions §22, Attributes §23, Unsafe code §24. The plan still uses the old numbers (§18 to §23) in the Reference table and in the Spec lines of M7, M8, M9, M10, M14 and in "Deliberately not covered". Annexes now have letters: A Grammar, B Portability issues, C Standard library, D Documentation comments, E Bibliography.
2. **The "three layers" text in the plan is outdated.** C# 12, 13 and 14 features are now in the draft (for example collection expressions §12.8.25, `params` collections §15.6.2.4, primary constructors §15.11.6 and §16.4, extension members §15.14, field-backed property §15.7.5, null-conditional assignment §12.24.7, compound assignment operators §15.10.6, partial members, the lock statement §13.13). The Learn feature-spec list now holds only C# 15 (`collection-expression-arguments`, `labeled-break-continue`, `extension-indexers`, `closed-hierarchies`, `unions`) and `unsafe-evolution` (memory safety). A direct check of `proposals/csharp-12.0/primary-constructors` returned 404.
3. Most of §15–§24 is assigned. The open items are small: nested types, partial members other than events and constructors, extension operators, custom task types, collection types, code analysis attributes, the `file` modifier and a few C# 12/13 features.
4. Badges: two C# 12/13 features that lessons teach or should teach have no entry in the **Badge** line (alias any type, `\e`). All other badge entries match "What's new in C# 12–15" (checked: primary constructors, collection expressions, lambda default parameters, `params` collections, `Lock`, extension members, null-conditional assignment, `field`, lambda modifiers, collection expression arguments, unions, closed hierarchies, extension indexers, labeled `break`/`continue`).
