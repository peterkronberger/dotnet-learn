Notes:

- Reference clause table rows for §6–§14 (number, slug, title) all match the current draft. §15–§17 and §19–§24 belong to the other spec audit; findings 1 and 2 are only what the pages of this part reveal.
- The draft foreword (`ms.date` 2026-11-20) lists the features added compared with the previous edition up to the C# 10 level (record structs, file-scoped namespaces, global using directives, extended property patterns, lambda improvements, improvements to structure types, …). The plan text in "Reference" (layer 2) is consistent with this. The foreword wording about the edition ("replaces ECMA-334:2026") differs from the plan fact "7th edition, December 2023". The Ecma site is not on learn.microsoft.com, so the plan fact is **not** changed here (finding 3).
